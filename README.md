# FacialTier Android app

This is a free Android WebView wrapper around the current FacialTier one-page UI.

## Build free on GitHub from a phone
1. Create a public GitHub repository.
2. Upload this entire project.
3. Open **Actions → Build FacialTier APK → Run workflow**.
4. Open the completed run → **Artifacts** → download `FacialTier-debug-apk`.
5. Extract it and install `app-debug.apk` on Android.

The app is a wrapper around the included local website. Production face-analysis, accounts, cloud storage and payments still need a backend before publishing as a full commercial app.
